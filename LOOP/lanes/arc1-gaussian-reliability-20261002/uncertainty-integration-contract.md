# Arc 1 uncertainty integration contract

Astra reviewed these scientific semantics on 2026-10-02. Luna implements the bounded Julia/R interface after the profile and FA numerical leaves pass review. Existing defaults and interval fields keep their current meaning.

1. Add explicit expert controls selecting `arc1_profile_v1` for the bounded Gaussian pedigree model with exactly two records per observed animal, or `arc1_bootstrap_v1` for the four-trait automatic selector using `arc1_v1`. Validate supported combinations before starting Julia computation. An omitted option preserves the legacy route.
2. A profile request owns one Arc 1 point fit, one common likelihood reference and five target results. Displayed estimates and likelihood must come from that same point fit. Never attach profiles to apparently different legacy estimates. Reuse existing fit/payload conventions where they accurately represent this result; unavailable post-fit quantities must remain explicit.
3. Bootstrap requires the outer `arc1_v1` selection result. Retain its original selected point estimates. Each fixed bootstrap attempt reruns the full frozen selector. Generate from the selected fitted covariance and fixed effects, with the same design and pedigree. Never initialize with generating truths or substitute bootstrap means for point estimates.
4. Store the new result separately as `arc1_uncertainty`. Explicit `confint()` method selection returns a long table with estimand, trait where applicable, segment, estimate, bounds, formed flag and exact status. A refused target retains a row with missing bounds. Keep unresolved observed segments in diagnostics, outside formed confidence sets. Preserve all disconnected formed components.
5. Return method and policy versions, estimand definitions, loaded source identity, source identity of the reference point fit, seed-derivation version, quantile convention, requested and usable bootstrap counts, failure causes, selection frequencies and the full per-attempt record. Formation alone does not establish calibration.
6. Bootstrap execution requires explicit B and exact seeds. An exact decimal UInt64 base seed may generate a versioned stream for ordinary users; the study runner passes its explicit canonical vector. Reject rounded or unsafe R numeric seeds. Keep every failed attempt and never replace it. Enforce the 99% fixed-budget usability requirement before returning formed percentile intervals.
7. Preserve interruption state and the partial attempt record. Validate it through mandatory live R/Julia tests using one frozen source version. Test mismatched point/source identity, unsupported designs, exact seed transport, disconnected sets, all failure statuses and legacy behavior.

API spelling may follow established repository conventions. These ownership, estimand, failure and provenance requirements are fixed. No calibration claim is made until the relevant original G4/G5 evidence passes.
