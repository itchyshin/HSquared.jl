## 1. Goal

Align the profile-v4 shared-winner certificate checker with its production certificate builders, reject a matching `:returned` certificate, and verify the bounded repair on current Julia source.

## 2. Implemented

- Added an adversarial test whose shared record and certificate both use `:returned` while matching source, value, and convergence. The checker leaves it unresolved with `:certified_shared_solution_mismatch`.
- Retained current-source focused tests, an engineering replay on the previously inspected N160 dataset, saved-result analysis and comparison, full Julia `Pkg.test()`, and a local documentation build.
- Astra reviewed the exact source and test hashes read-only and returned PASS for this bounded contract.

## 3a. Decisions and Rejected Alternatives

Kept `:returned` valid for raw callback history because it records a returned fit. Excluded it only as certificate evidence because production certificate constructors do not issue that status. The engineering replay reuses the inspected N160 dataset only to verify the repair; it is not independent calibration evidence.
