# Conditional 0.9.0 Gate B authorization

The maintainer authorizes Gate B only if the final independent audits, retained
H0/H1/H3 evidence, R–Julia parity, package checks, and release packet all pass
without a scientific-contract change. At that point, the programme may perform
the earned capability promotion, version updates, merge, tags, registry/CRAN
actions, and the 0.9.0 release.

This is conditional authority, not evidence or an immediate promotion. If any
required gate fails or the scientific fixture, estimand, or public contract must
change, hold the release and report the failed gate.
