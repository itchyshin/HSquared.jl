# Retained FA primary prefixes, 2026-09-30

These are immutable partial copies of the approved frozen Totoro campaign. They are diagnostic prefixes, with all attempts in the denominator; they do not establish campaign completion or a release decision. The original campaign continues without restart at its declared 5000 iterations per start. Folder names record the number of complete seed rows; each summary identifies exact source, driver and raw TSV pins. The scalar TSV cannot independently reconstruct full covariance matrices or objectives.
