# Method recommendation for the first automatic genetic FA rank selector

Status: design recommendation only, 2026-10-01. No selector, fit, simulation, or public R grammar was changed. Scope is the complete-response, four-trait, Gaussian pedigree animal model with the **same observations, trait-intercept fixed design, relationship matrix, and unstructured residual covariance at both candidates**. The fixed-rank fitter remains available.

## Recommendation

Offer only `K ∈ {0,1}` in the first selector. Define `K` as the number of *shared genetic factors*, not the rank of the whole genetic covariance. For both candidates, `G_K = L_K L_K' + diag(ψ)` with `ψ_i > 1e-4` in squared units of trait `i`; `L_0` has zero columns, so `G_0 = diag(ψ)` and every trait can still have positive additive genetic variance. `K=0` is **not** a zero-genetic-signal model. A no-signal boundary is a separate validation case, outside this strictly positive-uniqueness selector.

Use **minimum full-constant marginal-model REML AIC**, explicitly labelled `reml_aic_covariance`, as the provisional two-candidate rule:

`C_K = -2 ℓ_REML,K + 2 q_K`, with `q_K = q_G(K) + q_R`, and select the smaller eligible `C_K`.

This is a covariance-structure comparison on a common REML contrast space, not a claim that ordinary AIC theory proves correct biological factor count. The same-data, same-fixed-design condition is strict because the restricted likelihood depends on the fixed-effect space. The existing engine reports the full REML constant and already optimizes this likelihood [source: `src/multivariate.jl:844-856, 1035-1055, 1182-1188`]. Akaike's original formula is for a maximized likelihood with independently adjusted parameters; using the restricted likelihood here is a deliberate model-specific adaptation that must be tested for its selection behavior [Akaike 1974](https://doi.org/10.1109/TAC.1974.1100705), [Gurka 2006](https://doi.org/10.1198/000313006X90396), [Müller, Scealy and Welsh 2013](https://doi.org/10.1214/12-STS410).

For `T=4`, the generic FA covariance dimension is `q_G(K)=TK-K(K-1)/2+T`; hence `q_G(0)=4`, `q_G(1)=8`. The common unstructured `R` has `q_R=T(T+1)/2=10`. Thus `q_0=14`, `q_1=18`, and, if both fits are eligible, `K=1` wins exactly when `2(ℓ_1-ℓ_0)>8` (apart from a declared numerical-tie tolerance). The four fixed trait intercepts are common and removed by REML; including them in both penalties would add the same eight criterion units and leave the winner unchanged. The ten `R` parameters also cancel in the difference, but must remain in the displayed counts. At `K=1` there is no continuous rotation dimension, only a sign symmetry; at higher rank the quotient removes `K(K-1)/2`. These are **generic nominal** counts, not a certificate that a particular fitted loading pattern is identifiable [source: `src/multivariate.jl:1800-1817`].

Do **not** pass `rank=0` through the current `:factor_analytic` route: the validator requires `rank ≥ 1` [source: `src/multivariate.jl:693-703`]. The present `:diagonal` route is the mathematical rank-zero covariance shape, but it sets `ψ=exp(θ)` and has no `1e-4` floor; rank-one FA uses `ψ=1e-4+exp(θ)` [source: `src/multivariate.jl:706-721, 410-417, 463-473`]. A production selector should therefore fit an **internal floor-matched diagonal candidate** or first revise this parameterization under a separately reviewed contract, while leaving the public fixed-rank diagonal fit unchanged. Simply relabelling the current diagonal fit as a nested `K=0` comparator would be false whenever it lies below the FA floor. With a matched floor, `L_1=0` places the diagonal covariance in the closure of the `K=1` family; a zero loading is a singular point, not a regular interior rank-one model.

## What must be identifiable

For complete responses, write the marginal model as `y ~ N(X_full β, V_K)` with `V_K = Z_full(A ⊗ G_K)Z_full' + I_records ⊗ R` in the one-record-per-individual layout (and the corresponding record blocks for repeated measures). Holding `X_full`, `Z_full`, `A`, and observed records identical makes the fitted likelihoods comparable. The genetic and residual matrices are separately estimable only when the relationship/record design gives distinct covariance signatures. In the illustrative one-record-per-animal case with `A=I`, `V=I⊗(G+R)`, so freely varying `G` and unstructured `R` cannot be separated. Related animals or repeated records can supply distinction, but neither guarantees useful information in every dataset. Such weak identification can yield an apparently converged numerical optimum and unstable rank choice. This follows directly from the model covariance [source: `src/multivariate.jl:835-856`]; it needs a design-sensitive validation witness.

At the diagonal model, `L_1=0`, and the derivative of `L_1L_1'` with respect to each loading is zero. The extra loading directions are not first-order identified. A four-degree-of-freedom ordinary chi-square LRT, a generic AIC parameter count, or positive `ψ` cannot turn that singularity into a regular test. The rank-one loading map may also lose local rank when too few loadings are nonzero [source: `src/multivariate.jl:1828-1853`]. Boundary likelihood theory warns that conventional chi-square reference laws can fail, and even common chi-bar shortcuts are not automatically valid here [Self and Liang 1987](https://doi.org/10.1080/01621459.1987.10478472). Therefore report the *criterion difference* as a descriptive selection score, never a p-value or certainty about biological dimension.

The absolute `1e-4` uniqueness floor makes fits near that floor sensitive to trait units [source: `src/multivariate.jl:410-417, 938-948`]. The selector must retain per-trait distance-to-floor flags for **both** candidates and disclose the units issue. It should refuse unsupported input cells before fitting. A floor-adjacent converged fit may remain eligible for the provisional criterion, but selection must be flagged `boundary_sensitive`; the validation plan must test rescaling and can later justify a stronger refusal rule. Do not quietly raise or lower the existing floor to improve rank results.

## Eligibility and failure policy

Run the two requested candidates with a fixed, documented start and retry budget. Preserve every start and candidate row, including invalid, interrupted, unconverged, and unattempted outcomes. A candidate is **eligible** only if its selected attempt converged, has a finite full REML log-likelihood, finite covariance entries, positive-definite `R`, admissible `G`, and the matched uniqueness-floor contract. The current fitter can return a finite but unconverged FA attempt [source: `src/multivariate.jl:1115-1165`]; that is valuable diagnostic evidence, but not a selectable fit. Record any better nonconverged objective, near-floor flag, and across-start covariance disagreement. A candidate with such disagreement requires a predeclared numerical review rule before a winner can be called.

Return a selected rank **only if both candidates are eligible** and satisfy the numerical-comparability checks. If either candidate fails after the bounded retries, return `selection_status = :unavailable`, `selected_rank = nothing`, the full attempt table, and a plain reason. Do not silently select the sole surviving rank: that would describe optimizer success, not a comparison. The user can still request an explicit fixed-rank fit. Exact criterion ties choose `K=0`; a numerical near-tie should also choose `K=0` only under a predeclared tolerance based on verified objective accuracy, with the raw criterion difference reported. No universal tolerance is justified by the current evidence.

Any intervals or standard errors computed from the chosen model are **conditional on that selected rank**. They do not incorporate rank-selection uncertainty. Report the selection score and both candidates, and do not call the selected `K` a recovered biological truth without a separate, predeclared recovery and calibration study [Müller, Scealy and Welsh 2013](https://doi.org/10.1214/12-STS410).

## Why this criterion, and what could change it

- **Marginal ML AIC** is the cleaner direct use of Akaike's likelihood formula for population-average prediction, with all four fixed intercepts and the 14 or 18 covariance parameters counted. It needs a new, validated ML fitting path for *both* genetic structures; evaluating ML likelihood only at REML estimates is not an ML AIC. It is therefore a future alternative, not a reason to claim current implementation support. The distinction between marginal and conditional targets matters in mixed models [Vaida and Blanchard 2005](https://doi.org/10.1093/biomet/92.2.351), [Greven and Kneib 2010](https://doi.org/10.1093/biomet/asq042).
- **REML AIC** uses the existing optimizer and a common fixed-effect contrast space. It is the narrow usable starting rule for covariance selection, subject to the empirical checks above. It must not be labelled a universally valid or consistent rank estimator [Gurka 2006](https://doi.org/10.1198/000313006X90396).
- **BIC** would require a defended effective sample size for a correlated pedigree design, and its stronger penalty answers a different selection goal. Raw trait-record count, animal count, and pedigree-member count need not represent the same independent information. No unique `n_eff` is established for this cell, so BIC should be a prespecified sensitivity analysis only, never a hidden default [Müller, Scealy and Welsh 2013](https://doi.org/10.1214/12-STS410), [Delattre, Lavielle and Poursat 2014](https://doi.org/10.1214/14-EJS890).

The unresolved scientific evidence is **how often this provisional REML rule selects `K=0` or `K=1` under diagonal truth, weak and clear shared factors, small samples, weak pedigree information, and floor proximity**. The design can freeze the rule now; future predeclared simulation and comparator evidence determine whether it is fit for public default use. No user choice of criterion is scientifically essential before writing the bounded contract, provided the provisional status and fixed-rank escape are explicit.
