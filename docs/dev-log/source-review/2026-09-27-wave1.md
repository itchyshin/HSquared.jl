## Findings and fixes

### W1-01: high: inner PCG failure was discarded (fixed)

At `iterative_solve.jl:530–531,551–552,647–649,676–678,831–833,904–912`, the trace,
outer-fit, likelihood and information routes discarded the true residual or ignored the
standalone solver's convergence. Consequently a finite unconverged iterate could feed a
fit, log-likelihood, or confidence interval without an error. Outer relative-change
convergence does not prove linear-solver convergence.

Added `_require_pcg_convergence` and applied it after every downstream PCG consumption,
including the final BLUP solve. The standalone PCG APIs retain their existing diagnostic
return behavior. Downstream failures now throw `ArgumentError` with residual, tolerance,
and a suggestion to increase the iteration budget or improve conditioning. The check adds
no additional matrix-vector product: the PCG routine already computes the true residual.

Regression: a deterministic eight-record SPD fixture with `maxiter=1` is unconverged;
per-block/shared trace routes, fit, likelihood, information and interval routes must all
reject it. A successful information calculation is checked against an independent dense
marginal-covariance projector, not just the same MME assembly.

### W1-02: high: extreme two-sided p-values depended on sign (fixed)

`genomic.jl:2338–2352` formed a positive-z CDF as `1-upper`, then subtracted it from
one again. At +9 the CDF rounds to one and the p-value becomes zero; at −9 the small
upper tail survives. This contaminates marker scans and their multiple-testing values.
The red regression reproduced loss of sign symmetry/positive tails at ±8, ±9 and ±12.

The correction evaluates extreme two-sided normal probabilities through the existing
identity `P(|Z| ≥ |z|) = P(χ²₁ ≥ z²)`, whose gamma upper-tail implementation avoids
cancellation. For `|z| < 8`, the established central approximation is retained, evaluating
the small tail directly to preserve sign symmetry and existing cross-language fixtures.
No new package dependency is required. Independently tabulated extreme-tail
probabilities are checked to relative tolerance `1e-12`. Central-value compatibility is
confirmed by all 19 existing marker parity assertions in the final focused run.

### W1-03: medium: asymmetric genomic inputs silently changed model (fixed)

`genomic.jl:143–149,354–389,884–895` accepted arbitrary matrices, then used a
`Symmetric` view. Such a view chooses a triangle; it does not validate that the input is
symmetric. Added explicit symmetry checks for CPU genomic inverse, APY input and the mixed
marker cache precision. The regression uses `[2 .25; .5 2]` and checks rejection; existing
symmetric inverse/APY identities remain tested. The CUDA dispatch branch is untouched.

### W1-06: medium numerical risk: sparse quadratic cancellation (coordinator fixed)

`likelihood.jl:196,2332` and `iterative_solve.jl:833` compute `y′R⁻¹y − rhs′C⁻¹rhs`.
With a large fitted intercept these subtract two large quantities to recover a small
residual quadratic. Source algebra is correct; finite-precision shift invariance is not
established here. Add a small intercept-shift ladder (e.g. +0, +1e4, +1e8) and compare
with a residual-form dense oracle before asserting stability over response scales.
The coordinator's post-packet fixed-variance probe measured a real failure: adding
1e8 to every response changed sparse REML log-likelihood by about 6.69 while the
dense likelihood was invariant. A test-first 16-assertion ladder failed 8 assertions
across single-effect, multi-effect, matrix-free, and genomic-profile paths. The four
paths now evaluate the minimized joint quadratic from fitted residuals and random
effects (or the weighted fixed-effect residual for the genomic profile). The same
test passed 40/40 including existing wave-1 regressions. This repairs the tested
intercept-shift cell; broader scales and convergence claims remain open.

### W1-07: medium convergence risk: a small accepted step is not a stationary-point check

`likelihood.jl:502–532,2608–2624` halves steps for positive variances and accepts
relative-change convergence independently of a final score check. No likelihood-ascent
line search is performed in these blocks. Small damped steps can reflect a boundary or
ill-conditioned information. Add final-point scaled-score/likelihood checks in an
independent validation slice; do not infer stationary-point accuracy from the convergence
Boolean alone. Not changed here.

## Performance risks and measurement requirements

1. **Allocations per solve.** Matrix-free matvecs at `iterative_solve.jl:87–94,222–236`
   allocate record vectors, block products and output vectors. Each MC fit iteration also
   re-enters conversion/preparation in the solve and trace functions. Measure warmed
   allocations per matvec, per probe, per outer iteration, and peak memory before changing
   buffer ownership or using `mul!`. Correctness now fails closed when solves are starved.
2. **Typed workspace is a useful pattern.** `_MultiREMLWorkspace` (2126–2155) uses typed
   sparse arrays and explicit symbolic-factor reuse. Check `@code_warntype`/inference on
   first and reused factorization and closure calls; no type-stability proof was run here.
   Abstract public argument types are not themselves evidence of dynamic dispatch.
3. **Selected-inverse cost follows fill.** Takahashi scratch is one maximum-column-width
   accumulator plus stored L and selected values; it avoids a dense inverse. Kernel cost
   still depends on clique widths and lookups. Report `nnz(L)`, maximum width, sum of
   squared column widths, allocation and end-to-end time, not q alone. Historical timing
   comments are not fresh measurements from this review.
4. **Dense genomic output dominates memory.** APY allocates `Gd` and dense `Ginv` at
   364–374 despite reduced core inversion arithmetic. LOCO stores one dense precision per
   group (445–452); marker covariance caches are dense (884–907). Keep validation-scale
   wording. A core-size speedup does not establish large-population memory feasibility.
5. **Dispatch heuristic is not a resource bound.** `fit_multi_effect` selects exact for
   every K=1 model (1133), even with dense custom/genomic precision; K alone cannot bound
   fill. A future performance gate should measure symbolic fill or memory against a
   declared budget and preserve an explicit method override.
6. **SLQ error has several sources.** The reported MCSE (845–849) measures probe variation,
   not Lanczos truncation bias or solver error. The latter now receives a residual check.
   Validate step count, probe count and conditioning separately before an inference or
   speed-accuracy claim. The Lanczos basis itself costs O(N × steps) memory.

No performance optimization was introduced. Any future benchmark must compare matched
models, convergence and numerical output, with Julia/BLAS versions, thread caps, cold vs
warm times and memory recorded. No ASReml speed equivalence or interval coverage claim
follows from this packet.
