## Ranked findings, fixes, and required tests

### W2-01: P1: beta-binomial determinant is not a Laplace determinant

`src/nongaussian.jl:406-432` deliberately supplies expected Fisher information as `_fam_weight`. That may be used for a scoring step, but `:617-627` reuses it in the final determinant. Laplace integration requires the negative observed Hessian of the joint log density at its mode. The GLLVM path inherits the same issue through `src/genetic_gllvm.jl:257-259,304-314`.

A deterministic check at `BetaBinomialResponse(10,0.2), y=2, eta=0.7` gave observed curvature `0.4481077731` versus working weight `0.8198991878`. They are not interchangeable. `test/runtests.jl:781-808` explicitly tests expected information, and `:813-848` tolerates absolute error 0.2 against quadrature; neither verifies the required mode determinant.

**Fix/test:** separate scoring weight from observed curvature; compute/check the latter at the returned mode. If the joint curvature is not positive definite, refuse a Laplace value or seek a valid mode. Test a converged nontrivial beta-binomial mode against an independent finite-difference joint Hessian, including the final log determinant; repeat via GLLVM family dispatch.

### W2-02: P1: improper flat-effect integrals can be reported as converged finite objectives

`src/nongaussian.jl:575-630` has no proper-integral/separation guard. Four all-zero Poisson records with an intercept, `Z=Ainv=I`, variance 1 returned `converged=true`, `beta=-26`, `loglik=13.2257913526`. As the intercept tends to minus infinity the likelihood tends to one, so its flat-measure integral diverges; a small score does not establish a finite mode.

The candidate checks all-zero Poisson traits in `src/genetic_gllvm.jl:222-233`, but four all-zero Bernoulli responses still returned `converged=true`, `beta=-26.20289477`, `loglik=13.3272387385`. Constant successes/failures in binomial and separated fixed-effect designs need the same scrutiny. The new Poisson tests at `test/genetic_gllvm_trait_effects.jl:20-41` cover one specific improper case, not those families/designs.

**Fix/test:** detect/refuse improper integrated objectives for supported families and design directions, or narrow the supported design/family contract explicitly. At minimum exercise Poisson all-zero intercept; Bernoulli all-zero/all-one; binomial all-failure/all-success; and a separated covariate design. A finite objective and `converged=true` must be impossible in those cases. Preserve the valid Poisson all-zero case with no fixed effects.

### W2-03: P1: covariance/precision validation silently changes or admits invalid models

Multivariate fitters invert `Symmetric(Ainv)` at `src/multivariate.jl:889-892,1067-1070`; only finiteness is checked. `multivariate_mme` similarly accepts finite nonsymmetric/indefinite precision at `:526-540`. RR wraps `K_g` in `Symmetric` at `src/random_regression.jl:330-337` and inverses `Symmetric(Ainv)` at `:463-466`, without verifying symmetry/positive definiteness of the original precision. Laplace/GLLVM kernels use the full matrix in gradients/quadratics but `Symmetric` in solves/determinants (`src/nongaussian.jl:584-627`; `src/genetic_gllvm.jl:195-198,267-320`), so a nonsymmetric input can even mix incompatible objectives.

Confirmed: RR MME accepts `K_g=[1 0;9 1]` and silently uses the upper-triangle identity covariance. `test/runtests.jl:7462` checks nonsymmetric G0, and `:10050-10053` checks negative K_g and shapes, but those do not protect the other matrices/routes.

**Fix/test:** validate dimensions, finiteness, symmetry with an explicit tolerance, and positive definiteness of relationship precisions before coercion/inversion; use the validated matrix consistently. Apply the covariance guard to RR K_g and its initial value. Test nonsymmetric, indefinite, singular and nonfinite matrices through every entry point; include a finite indefinite Ainv whose marginal V would otherwise remain positive definite under large residual variance.

### W2-04: P1: covariance standard errors accept the wrong model class

`fit_multivariate_repeatability_reml` returns `genetic_structure=:unstructured` plus `permanent_covariance` (`src/multivariate.jl:1135-1156`). `multivariate_covariance_standard_errors` only checks the structure token (`:1416-1439`), then rebuilds an animal-only G0/R0 likelihood. Passing the repeatability result silently ignores P0 and yields the wrong observed information if that matrix is positive definite. The interval helper routes through this same path (`:1498-1515`). The LRT count helper also omits PE covariance parameters (`:1542-1561`).

**Fix/test:** reject repeatability results from animal-only inference helpers until a P0-aware path exists; enforce the fitted-model class before computing anything. Add a repeatability fixture with nonzero P0 and assert clear refusal or parity with an independent three-covariance Hessian. Test mixed animal-only/repeatability LRT inputs too. Existing animal-only SE tests at `test/runtests.jl:9575-9602` do not cover this dispatch hazard.

### W2-05: P2: the integrated VA value is advertised as a lower bound without that guarantee

`src/nongaussian.jl:696-714` says `elbo` is a lower bound on the beta-integrated marginal. The algorithm optimizes a conditional-on-beta variational objective, then adds a local Laplace beta correction (`:781-794`). Laplace integration of a lower-bound integrand does not preserve an integral inequality. The Gaussian reduction can be exact, but does not establish the non-Gaussian bound. `test/runtests.jl:8748-8757` explicitly leaves the non-Gaussian value gate open; the diagonal/full bound comparison at `:8766-8772` fixes beta (`p=0`).

**Fix/test:** describe this as the actual hybrid approximation and remove the general lower-bound claim, or derive/implement a joint variational distribution including beta with a valid integrated bound. Check a small non-Gaussian case against independent integration over both beta and random effects. The covariance fixed-point loop at `:678-691` also returns after 200 steps without a convergence flag: outer convergence should require a converged covariance solve.

### W2-06: P2: scale-dependent PSD check returns impossible correlations

`src/multivariate.jl:20-36` uses the absolute eigenvalue tolerance `-1e-8`. Confirmed: `genetic_correlation([1e-10 2e-10;2e-10 1e-10])` returns off-diagonal correlation `1.9999999999999998`; the covariance has a negative eigenvalue of the same order as its positive eigenvalues. This affects RR correlation surfaces through `src/random_regression.jl:135-137` too.

**Fix/test:** use a scale-relative PSD check and finite-input guard; retain legitimate rank-deficient PSD inputs. Test the same indefinite and valid PSD matrices scaled over several orders of magnitude, and require valid correlations in [-1,1] within roundoff.

### W2-07: P2: extractor metadata and heritability contracts are inconsistent

- RR supplied MME builds IDs without checking their length (`src/random_regression.jl:351-355`); confirmed one ID accompanies four coefficient rows. `fit_laplace_reml` similarly collects IDs at `src/nongaussian.jl:1125` without a length check before returning `NonGaussianFit`. Validate IDs before compute and test wrong-length inputs.
- Gaussian `nongaussian_heritability` ignores supplied predictor variance (`src/nongaussian.jl:1402-1409`), despite the general denominator contract at `:1537-1558`. Confirmed `V_A=1, sigma_e2=1, predictor_variance=8` returns 0.5 and total variance 2. Choose and document a single convention: population total variance implies 0.1; conditional heritability should reject or explicitly exclude the keyword. Test the nonzero predictor-variance case.
- Any binomial trial vector is treated as varying by the general extractor (`:1585-1592`), whereas the three-field envelope correctly recognizes constant vectors (`:943-963`). A constant vector and equivalent scalar therefore give different availability of observation-scale h2. Add scalar/constant-vector parity and retain refusal for genuinely varying trials.
- Supplied h2 inputs have no finite/nonnegative variance checks (`:1606-1613`); reject invalid variance and predictor-variance inputs before transformations.

### W2-08: P2: uncertainty helpers do not enforce their fit/convergence prerequisites

`covariance_structure_lrt` (`src/multivariate.jl:1615-1652`) uses only parameter counts and likelihoods; it does not reject nonconverged fits, unequal trait dimensions, or unsupported/non-nested structure pairs. `multivariate_covariance_standard_errors` (`:1416-1446`) does not reject a nonconverged point fit. `laplace_reml_interval` (`src/nongaussian.jl:1358-1374`) proceeds after a nonconverged or search-boundary fit and drops the fit's boundary flag. A curvature matrix or nominal degrees of freedom cannot repair these prerequisites.

**Fix/test:** gate inference on correct model class, dimensions, supported nesting and successful finite fits. Preserve/check the variance search-boundary status; report unavailable endpoints when profile evaluations fail. Test deliberately nonconverged and boundary fits, mismatched traits, and a diagonal-vs-lowrank pair that is not nested. Document that identical response/design provenance remains the caller's responsibility unless stored/verified.

### W2-09: P2: GLLVM family/input contract is broader than its dispatch

`src/genetic_gllvm.jl:188-216` accepts every `ResponseFamily`, including `BinomialVectorResponse`, whose validator succeeds with a per-trait response column, but its closures at `:257-259` call `_fam_score/_fam_weight/_fam_loglik` directly without `_fam_record`; no such vector-family kernels exist. This reaches a MethodError instead of a supported fit or explicit rejection. The same input block lacks explicit finite-Y/X/loading/precision checks; scalar family constructors also accept positive infinity (`src/nongaussian.jl:30-35,83-88,149-157,170-175`).

**Fix/test:** explicitly restrict supported family types or resolve per-record family state consistently within each trait. Test per-trait vector trials, invalid family-vector members, nonfinite Y/X/loadings/Ainv, zero-column loadings, and infinite family parameters; require informative argument errors. Keep malformed input rejection separate from optimizer proposal failures.
