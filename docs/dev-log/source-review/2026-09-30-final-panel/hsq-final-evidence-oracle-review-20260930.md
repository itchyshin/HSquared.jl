## 4. False-pass findings

1. **Required source/test coverage absent.** `check_files` rejects a truly empty inventory but accepts one containing only Project.toml. An inventory with zero source and zero test entries printed JULIA_PASS. Adding an unlisted source file also printed PASS. Require source and test entries and equality with the intended source/test file universe, including Project/Manifest and declared protected inputs. The real current freeze contains 24 source and 74 test entries; its correctness does not enforce the checker's schema.
2. **Consumed artifacts need not be pinned.** A nonempty artifacts map can contain only an unrelated file. Changing result JSON to another successful command, or changing Julia HTML while retaining a required term, still printed PASS. Require every consumed freeze, result, log, and rendered page in the artifact inventory; reject omitted dependencies before interpreting them. R tarball hash comparison from the legacy wrapper also needs preservation or equivalent mandatory pinning.
3. **R rendered surfaces omitted.** R scope never reads rendered-R-surface-checks or HTML. Removing an R page caveat was accepted. Require nonempty named R page evidence, matching file hashes, and required visible caveats in the R scope. Apply safe relative path rules to rendered entries too.
4. **Vacuous terms and result schema.** An empty required_terms list accepted a page with no caveat. JSON exit_status=false equals zero in Python; missing over_estimate defaults to success. Require nonempty string term lists, integer exit_status, and an explicit Boolean over_estimate=false. Command identities and live bridge project/required flag should be tied to their frozen wrapper contract. Raw HTML substring presence is only a text-presence check, not visual inspection or proof of visible prose.

## 6. Wrapper assessment

Its docs branch checks only HTML existence and its R branch uses receipt hashes, so it is not equivalent to the intended unified contract.
