# Ordinary-start MV+PE protocol candidate

Date: 2026-10-06  
Status: revised draft for independent scientific challenge. The H2 project is authorized to continue; this MV+PE study is not yet admitted for execution because its protocol and exact source freeze have not passed review. No confirmation seeds have been allocated or inspected for this version.

## Scope and intended claim

Estimate and validate the declared two-trait Gaussian animal-plus-permanent-environment route through the Julia engine and its R interface. The engine estimates unstructured additive-genetic covariance `G`, permanent-environment covariance `P`, residual covariance `R`, and trait-specific repeatability. The intended claim is limited to the DGP and record design below, ordinary data-only initialization, and the frozen software route. It does not establish performance for other pedigree structures, trait counts, missing records, inheritance systems, interval calibration, or production-scale data. A successful study is evidence for this cell, not general validation of the full MV+PE family.

## Candidate data-generating cell

Use the current retained `sim/phase4_multivariate_repeatability_recovery.jl` design as the source template, with these values:

- 2 Gaussian traits, intercept 2 per trait, complete observations, and 4 records per animal.
- Half-sib pedigree with 8 sires, 16 dams, and 48 offspring, using the existing deterministic allocation and ID ordering.
- `G = [1.00 0.30; 0.30 0.80]`, `P = [0.50 0.10; 0.10 0.40]`, and `R = [0.80 0.15; 0.15 0.70]`.
- Fit `fit_multivariate_repeatability_reml` by REML with the existing pedigree relationship and record layout.
- Repeatability targets are `t_k = (G_kk + P_kk)/(G_kk + P_kk + R_kk)`, giving `t1 = 1.5/2.3` and `t2 = 1.2/1.9`.

This has 72 pedigree animals including founders and 288 bivariate records. Before freeze, verify exact parent allocation, covariance factorization, row ordering, and the complete transitive source list. The retained eight-seed truth-started screen is historical diagnostic evidence only; none of its seeds or outputs count toward this study.

## Ordinary start and numerical formation

Call the Julia route without passing `initial` matrices. Its current engine start is equal diagonal thirds of empirical trait variances for `G`, `P`, and `R`. The current result does not return actual starts or a detailed optimizer termination reason; add reviewed instrumentation before any run and retain those values. Until instrumentation is in place, any independently reconstructed start must be labelled reconstructed, never observed. The code path may access observed records for empirical-variance starts but must not access generating parameters directly. R parity must invoke the same Julia default. Hash serialized input rows, pedigree, design matrices, and actual starts so each paired route uses identical inputs.

The current optimizer uses Nelder-Mead and reports a convergence Boolean, iteration count, and finite REML fit; it does not expose a detailed termination reason or stationarity certificate. Instrument only fields the optimizer actually supplies, and have tests prove their mapping. Distinguish ordinary-fit formation from numerical-reference, comparator, and R-parity outcomes. Formation is evaluated uniformly on every attempted Julia ordinary fit: successful return; optimizer convergence true; finite estimates; symmetric positive-definite `G`, `P`, and `R`; finite repeatabilities in `[0,1]`; and no unplanned warning or fallback. Failures to generate inputs or return a valid ordinary fit count as unformed. A reference shortfall, comparator failure, or R parity failure is recorded in its own gate and never changes the formation result or selectively removes a seed from the ordinary recovery denominator.

Independently recompute the objective at every returned parameter vector. On a preselected subset and every predeclared flagged attempt, run a frozen expanded reference search. A reference shortfall beyond a frozen tolerance fails the numerical-reliability gate but does not rewrite formation or replace the ordinary estimate. The reference specification must freeze its deterministic starts, budgets, parameter domain, stopping/status rules, shortfall calculation, numerical tolerance, and behavior when no valid reference solution is found. Define flags before outcomes from optimizer status, objective replay mismatch, warning/fallback, or covariance boundary diagnostics. Near-boundary but positive-definite estimates stay in the sample and receive a boundary label. Report distinct matrices with nearly tied objectives as an empirical ambiguity, not as agreement or proof of global optimality. The reference search is best-found evidence only, never a global-optimum claim. Current source cannot supply a gradient norm; do not require or claim one unless the engine changes and is re-reviewed.

## Formation and scientific recovery

Report formation and scientific recovery separately. A formed fit must have successful optimizer termination under the frozen rule, finite symmetric positive-definite covariance estimates, finite repeatability in `[0,1]`, and no unplanned warning or fallback. Count every other outcome as unformed. Candidate confirmation gate: the two-sided 95% Wilson lower bound for formation is at least 0.95. This floor defines the reliability target for this cell. Pilot formation is a feasibility screen only: report the exact Wilson interval and failures; 30/30 does not establish a population rate of 95%. Failure of the frozen pilot rule holds confirmation.

The confirmatory inferential family is exactly 11 quantities: six diagonal variances (`G11`, `G22`, `P11`, `P22`, `R11`, `R22`), three per-fit component correlations (`rhoG`, `rhoP`, `rhoR`), and two repeatabilities. Compute each correlation within each formed fit as its covariance divided by the square root of its two diagonal variances, then summarize the correlation estimates; averaging covariance elements first defines a different estimand. Retain the three off-diagonal covariances with bias, SD, MCSE, RMSE, and quantiles as descriptive results, outside the 11-target gate. Report all-attempt formation and failures, then among formed fits report each target's mean, bias, standard deviation, Monte Carlo standard error, RMSE, and empirical 2.5%/97.5% quantiles. The inferential recovery claim is only about Monte Carlo mean bias conditional on formation; it does not imply that individual fits are precise or that failures are ignorable.

Candidate practical margins for review:

- Each covariance diagonal's absolute mean bias is no larger than 10% of its true value.
- Each component correlation derived from `G`, `P`, or `R` has absolute mean bias no larger than 0.10.
- Each repeatability has absolute mean bias no larger than 0.05.

This replaces the ambiguous geometric-mean covariance margin with a scale-free correlation margin. Candidate confirmation rule: family-wise 95% simultaneous intervals for all 11 conditional mean biases lie wholly inside their corresponding margins. Use a predeclared Bonferroni-adjusted t interval only if its assumptions and computation are checked; also retain a seed-level bootstrap interval as a sensitivity summary, not as a substitute gate. Report marginal and simultaneous intervals distinctly and confirm the formed denominator for every target. The confirmatory gate fails if intervals are too wide even when point estimates are near truth. Do not widen thresholds or add attempts after observing confirmation results.

These margins remain proposals, not adopted thresholds. They are declared practical benchmark targets for this simulated cell, not evidence of user relevance or sufficient study precision. The candidate pilot screen requires at least 29/30 uniformly formed ordinary fits; one complete status receipt for each of the 30 attempts; objective replay for every returned parameter vector; and a frozen reference result for every formed ordinary fit. When an attempt returns no parameters, record replay and reference comparison as unavailable with reason; this is an unformed attempt and consumes the one allowed pilot formation failure. A returned vector that cannot be replayed, or a formed result without a valid reference comparison, independently holds the pilot. Require complete comparator and R-parity outputs without skips for every required case, and zero unexplained source/input hash mismatches. At pilot admission, specify the exact selected-reference count and comparator count, with all flagged fits added; no missing comparison is silently omitted.

For precision qualification, let `n_j` be the number of formed pilot estimates for target `j` and compute its SD. Use a normal-model planning approximation for its upper SD bound, `sqrt((n_j-1)*s_j^2 / chi_square_quantile(alpha/11, n_j-1))`, where `alpha=0.10`; this is a 90% family-wise bound across 11 targets only under normally distributed estimates across independent seed replicates. The 11 targets are correlated because they share simulated datasets; Bonferroni adjustment does not require independence across targets. Its coverage claim depends on that normal-model assumption. Project the family-wise Bonferroni t-interval half-width at the minimum confirmatory formed count of 389/400. The projected half-width for every target must be no greater than its frozen practical margin; otherwise hold confirmation and revise under a new protocol. Define sample skewness as the adjusted Fisher-Pearson coefficient `sqrt(n_j*(n_j-1))/(n_j-2) * m3/m2^(3/2)` for `n_j > 2`. If any target has absolute pilot skewness above 1 or any fitted diagonal variance is at most `1e-4` times its true DGP value, treat the normal approximation as inadequate and hold for redesign; also report histograms and boundary counts. Passing these screens does not prove normality. A bootstrap sensitivity summary uses seed-level resampling with 10,000 resamples, percentile intervals, and a dedicated MersenneTwister RNG whose seed is allocated by a separate `mvpe_pilot_bootstrap` manifest stream, independent of data generation and optimization. The 95% Wilson lower formation bound of at least 0.95 requires at least 389 formed ordinary fits out of 400. The 30-attempt pilot cannot establish that population formation rate; even 30/30 has a Wilson lower bound of 0.8865. If pilot data do not support the t-interval assumptions, hold and redesign before confirmation rather than switching interval methods after observing confirmatory results. No current evidence establishes joint probability that all 11 confirmation intervals will fit within margins. Freeze the 400-attempt maximum before confirmation; a larger study requires a new reviewed protocol and, if projected above three hours, separate approval after the measured pre-run.

## Independent comparator and Julia/R parity

Before outcomes, fix a confirmation comparator subset of 40 seeds by manifest hash and add every flagged ordinary fit. Run the comparator for all 30 pilot attempts and all development attempts used for method qualification. Pin `sommer`, `nadiv`, R, Julia, and package environments. Require comparator attempts without dependency or layout skips. Retain full `G`, `P`, and `R` from both implementations. Compare diagonal variances by relative difference `abs(a-b)/max(abs(a),abs(b),scale_floor)` with a frozen scale floor tied to each true DGP variance; compare correlations by absolute difference. Freeze tolerances separately from recovery margins. A failed or skipped comparator is an unmet comparator gate, never dropped from its denominator, but it does not change ordinary-fit formation or its recovery denominator.

The current comparator checks two diagonal elements with absolute tolerance 0.35 and permits skips. That is insufficient. Do not require the two software packages' printed likelihoods to match until constants, scaling, and variance-domain conventions are reconciled. Instead, define one common objective evaluator for identical serialized inputs and evaluate both implementations' returned parameter matrices under it; independently validate the evaluator before use. Compare objective differences only within that evaluator, with a tolerance justified by numerical precision. Agreement on the same data does not independently establish scientific recovery, and the comparator never rescues a failed ordinary fit. The expanded reference must specify its exact multistart matrix, deterministic start generation, optimizer sequence and budgets, covariance parameterization/domain, convergence/stop rules, best-found objective, difference calculation, threshold, and unresolved/no-reference status. Relative variance comparison near zero must use a prespecified component-specific scale floor; valid near-boundary fits remain in outputs, while exact boundary handling must match both models' parameter domains. The 40-seed subset is a candidate and must pass a bounded reviewed development feasibility run before pilot/confirmation admission; freeze numerical tolerances before pilot outputs are inspected.

For Julia/R parity, serialize and share identical data, pedigree, and design inputs, then hash the R-produced backend payload and prove equality to the frozen serialized inputs at the Julia boundary. Compare all covariance matrices, per-fit correlations, heritability/repeatability, fixed effects, loglikelihood convention metadata, status, warnings, iterations, and failure reason. Freeze field-specific absolute/relative tolerances separately from recovery margins. Require identical normalized status and failure classification, with cross-language errors mapped through an explicit frozen table; missing required fields, skipped backend runs, or warning suppression fail parity.
